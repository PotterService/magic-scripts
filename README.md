Bow Magic Scripts

A modular browser enhancement platform powered by GitHub, custom scripts, and expandable tools.

✨ About

Bow Magic Scripts is a customizable browser enhancement system designed to make the web more powerful, flexible, and personal.

Instead of installing dozens of separate scripts manually, Bow Magic Scripts creates a centralized platform where users can:

manage scripts easily
enable or disable features
receive updates through GitHub
expand functionality over time
customize supported websites
experiment with new browser tools

The project is built around the idea of modular growth. New features, tools, and systems can be added without rebuilding the entire platform.

Whether you are a casual user, creator, tester, or developer, Bow Magic Scripts is designed to evolve alongside your needs.

🔧 How To Install the Extension
Step 1 — Download the Repository

You can either:

clone the repository using Git
or download the ZIP directly from GitHub

Example:

git clone https://github.com/USERNAME/REPOSITORY.git

Or:

Open the repository on GitHub
Click the green Code button
Select Download ZIP
Extract the ZIP file
Step 2 — Open Browser Extensions

For Chromium browsers such as:

Google Chrome
Opera
Microsoft Edge
Brave
Vivaldi

Open:

chrome://extensions/
Step 3 — Enable Developer Mode

Enable:

Developer Mode

Usually located near the top-right corner of the extensions page.

Step 4 — Load the Extension

Click:

Load unpacked

Then select the extracted repository folder.

The extension should now appear in your browser.

Step 5 — Open the Manager

After installation:

click the extension icon
open the manager/dashboard
enable the modules you want
refresh supported websites
