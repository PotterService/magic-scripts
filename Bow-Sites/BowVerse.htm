What Is BowVerse?

BowVerse is a growing collection of browser-powered projects built around customization, creativity, automation, and experimental web systems.

Instead of being one single app, BowVerse is an ecosystem where multiple Bow projects can connect together over time.

The goal is to create useful, fun, and expandable tools for creators, gamers, home users, developers, and anyone who likes customizing their web experience.

Bows MiniNet

MiniNet is a browser-based custom domain routing system. It allows supported MiniNet domains to route to pages, tools, dashboards, local servers, and custom web experiences.

  • Custom MiniNet domains
  • Local browser routes
  • Expired domain handling
  • Official, rented, permanent, and temporary domain support
  • Home server and local network shortcuts
Active Project

Bow Magic Scripts

Magic Scripts is a modular browser enhancement system for custom scripts, site tools, dashboards, and web enhancements.

  • Script manager dashboard
  • Enable and disable tools
  • GitHub-powered updates
  • Site-specific addons
  • Custom browser features
Active Project

Bow Sites

Bow Sites are lightweight pages, portals, tools, and documentation pages used by BowVerse projects.

  • Project information pages
  • MiniNet pages
  • Script documentation
  • Experimental portals
  • Hosted HTML tools

Important Notice

BowVerse is an experimental hobby project and is under active development. Some systems may change, break, improve, or be redesigned over time.

MiniNet domains are not normal public internet domains and may require the Bows MiniNet plugin to work correctly.

Magic Scripts and MiniNet systems are designed with user safety in mind. Public script marketplaces and public user-submitted scripts are not planned due to security risks.
