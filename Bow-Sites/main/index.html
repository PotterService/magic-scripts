What Is MiniNet?

Bow MiniNet is an experimental mini web system designed for Bow-style domains, custom pages, tools, demos, and lightweight web experiences.

It is designed to create a connected ecosystem of custom experiences that feel like a small internet within the internet.

Important Notice

Bow Domains are not normal public internet domains. They are custom MiniNet addresses designed to work through the Bow MiniNet system.

This launcher does not browse the entire internet. It only opens supported MiniNet pages and custom Bow-style addresses.
