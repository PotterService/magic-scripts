Unavailable Print Cards

Use data/unavailable_print_cards.json to mark Creator Vault cards that cannot be requested as single prints.

[
  {
    "cardName": "Auravelle, Prism Overlord of Infinity",
    "reason": "Only obtainable from packs."
  }
]

You can match by cardName or id. The reason appears on the card view page.
